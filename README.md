🛒 Supermarket Sales Analysis

📌 Project Overview

This project analyzes supermarket sales data using Python, SQL, and Power BI to identify sales trends, top-selling products, branch performance, and customer preferences.

🛠️ Technologies Used

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL
- Power BI
- Jupyter Notebook

📊 Key Insights

- Top Product: Cheese — ₹27,906.30
- Best Branch: Branch C (Mumbai) — ₹72,469.45
- Top Category: Beverages — ₹56,108.24
- Popular Payment Method: UPI — 127 transactions
- Average Customer Rating: 3.99/5

🎯 Business Recommendations

- Improve stock management for popular products.
- Analyze the best-performing branch.
- Support popular payment methods.
- Improve customer satisfaction.
